# Design Fidelity Rule

This project uses a strict Pattern -> Mockup -> Web implementation workflow.

## Standing rule
1. Identify the selected design pattern and state its design intent before implementation.
2. Treat the approved mockup as the visual source of truth for the test implementation.
3. Keep the selected pattern and approved mockup visible during implementation and review.
4. Compare the implementation against the mockup for layout, whitespace, typography, image ratios/crops, colour, hierarchy, rhythm, navigation and mobile adaptation.
5. Do not simplify the implementation into a generic landing page merely because that is easier to code.
6. When real content or photos require adaptation, preserve the pattern's design intent and explain any deliberate deviation.
7. Do not present a preview as a faithful implementation until the mockup comparison has been performed.

## Uma Academia H+
- Base pattern: Pattern H — Editorial Brand Experience.
- H+ intent: Pattern H editorial/personal-brand character + clearer conversion/navigation + quiet Kyoto editorial sensibility.
- Approved H+ mockup characteristics: fixed left navigation, black top utility bar, editorial three-line hero typography, layered/polaroid-style photo collage, generous cream whitespace, process strip, horizontal Featured Private Tours, restrained violet accent, and photo-led storytelling.

This rule exists because mockup-to-web fidelity is a required quality gate, not an optional styling preference.
